# Visibilio Agent Guidelines

## Before coding

Read `README.md`, `PRODUCT.md`, `ROADMAP.md`, and `DESIGN_SYSTEM.md` before making changes.

## Workflow

1. Understand the task
2. Inspect the existing code
3. Propose a plan
4. Identify files to change
5. Implement the smallest useful change
6. Run relevant checks and tests
7. Summarize changes, tests, limitations, and next steps

For larger changes, wait for approval after planning.

## Rules

- Product and UX decisions remain human-driven.
- Do not silently invent product goals, user types, or major architecture.
- Prefer deterministic, measurable evidence for confirmed issues.
- Keep AI interpretation separate from detection logic.
- Avoid unnecessary dependencies and premature abstractions.
- Use TypeScript, accessible HTML, focused components, and responsive layouts.
- Include regression tests for important bug fixes.
- Never claim a feature works unless it has been tested.
- Do not claim full accessibility, compatibility, or complete issue coverage from limited checks.
