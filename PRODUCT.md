# Visibilio Product Definition

## Problem

Website owners often notice that something looks wrong without knowing the cause, impact, affected viewport, or possible fix. Visibilio connects understandable explanations with technical evidence.

## Target users

- **Website owners:** clear explanations, visual evidence, and actionable next steps.
- **Frontend developers:** reproducible checks, measurements, selectors, and implementation hints.
- **Designers:** visual evidence and qualified layout/readability observations.

## Core flow

**Detect → Explain → Show → Suggest → Re-test**

## MVP

Included:

- Test URL input
- Controlled viewport scanning
- Deterministic horizontal-overflow detection
- Screenshot/evidence capture
- Issue reports
- Plain-language and technical explanations
- Basic, explicit severity rules

Not initially included:

- Full WCAG certification
- Guaranteed browser compatibility
- Automatic code modification
- Complete visual design judgment
- Guaranteed conversion optimization
- Exhaustive issue detection
- Complex billing, teams, or crawler infrastructure

## Principles

Measured evidence comes first. Subjective observations must be qualified as suggestions, not stated as confirmed defects. AI should initially interpret structured findings rather than replace deterministic checks.

## Early success criteria

A user can scan a test page, reproduce a finding, see evidence, understand the issue, inspect technical context, and re-test after a change.
